# Document Contract

Primary output is chat-ready text for the project's own strategy chat —
same convention as `m2-project-status-report`'s regular reports.

## Purpose

Use this reference for the offboarding retrospective report.

## Expected Output

Short chat-ready text, Markdown/plain text. Do not use CSV.

## Target Folder

If a copy is saved:

`G:\My Drive\QA_Management\20_M2_Project_Management\<Project>\private\status_reports`

Suggested naming: `offboarding_retro_<Project>_<Person>_YYYY-MM-DD.md`

## Versioning

One-time event artifact — do not overwrite an existing saved retro; add a
`_vN` suffix if the target file already exists.

## Source Rules

- Confirm the stop is real (a date communicated), not a still-open Risk
  Management situation.
- Prefer direct client/lead feedback over secondhand accounts when both
  exist; note the feedback channel per
  `../m2-project-risk-report/SKILL.md`'s confidence framing if relevant.
- Cross-check whether `Replacement`/Risk Management already ran for this
  rate before writing "что предпринимали" from memory.

## Missing Evidence

If the real stop cause isn't clearly established, say so explicitly
rather than defaulting to a vague label — this report exists specifically
to prevent the same avoidable cause recurring on the next hire for this
rate.

## Language

Russian by default. Preserve standard English terms as-is.
