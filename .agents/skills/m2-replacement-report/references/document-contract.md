# Document Contract

Primary output is chat-ready text for the project's own strategy chat —
same convention as `m2-project-status-report`'s regular reports.

## Purpose

Use this reference for the five Replacement-stage chat posts (Launch,
Screening results, CV review, Post-interview feedback, Close-out).

## Expected Output

Short chat-ready text per stage, Markdown/plain text. Do not use CSV.

## Target Folder

If a copy is saved:

`G:\My Drive\QA_Management\20_M2_Project_Management\<Project>\private\status_reports`

Suggested naming: `replacement_<stage>_<Project>_YYYY-MM-DD.md` (stage
one of `launch`, `screening`, `cv-review`, `feedback`, `close`).

## Versioning

Each stage post is a one-time event artifact tied to that point in the
process — do not overwrite an earlier stage's saved copy; add a `_vN`
suffix only if redrafting the same stage.

## Source Rules

- Stage 1 needs the real reason Replacement was triggered — don't draft
  it generically.
- Stages 2-4 need real screening/CV-review/interview outcomes, not
  placeholder candidate assessments.
- Stage 5 needs the client's actual final decision, not an assumed
  outcome from silence.

## Missing Evidence

If the requested stage's underlying evidence isn't available yet (e.g.
asked to draft screening results before screenings happened), say so
rather than fabricating placeholder candidates.

## Language

Russian by default. Preserve standard English terms as-is.
